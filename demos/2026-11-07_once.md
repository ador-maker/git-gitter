# 2026-11-07 — Once — run a handler a single time

```js
// Once: wrapper that only lets the first invocation through
function once(fn) {
  let called = false;
  return (...args) => { if (!called) { called = true; return fn(...args); } };
}
const init = once(() => console.log('initializing…'));
init(); // logs
init(); // no-op
```

Useful for init flags, first-click tracking, and lazy initialization.
