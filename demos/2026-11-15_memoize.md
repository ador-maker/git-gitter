# 2026-11-15 — Memoize an expensive call

```js
// Memoize: cache results per argument so it computes once per input
function memoize(fn) {
  const cache = new Map();
  return (x) => {
    if (cache.has(x)) return cache.get(x);
    const v = fn(x);
    cache.set(x, v);
    return v;
  };
}
const fib = memoize((n) => n < 2 ? n : fib(n - 1) + fib(n - 2));
fib(40); // instant after the first run
```

Repeated calls with the same argument skip the recomputation entirely.
